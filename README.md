

## Project Description
The Housing Price Prediction System is a machine learning project that predicts
housing-related values based on demographic and geographic data.

The system performs data cleaning, feature encoding, scaling, and applies a
Linear Regression model to generate predictions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Dataset
File: housing.csv

Dataset includes:
- Longitude & Latitude
- Housing Median Age
- Total Rooms & Bedrooms
- Population
- Households
- Median Income
- Ocean Proximity
- Median House Value

## Project Workflow
1. Load dataset
2. Remove missing values
3. Encode categorical feature (Ocean Proximity)
4. Apply feature scaling
5. Prepare final dataset
6. Train Linear Regression model
7. Evaluate using R2 Score

## Algorithm Used
- Linear Regression
